# Agent ID Pioneer — Neon City

A free open-world style NFT badge for Binance Agent ID holders on BNB Chain.
Built for the **Binance Agent ID Hackathon 2026** (submission period 18 Nov – 9 Dec 2026).

**Live site:** https://zhinu27.github.io/agent-id-pioneer/  •  **Contract:** `0xDE4C3c4ea57963E52feD2Ec772A819A8d0c702fd` (BSC, verified on Sourcify)

**Theme:** Neon City — a GTA-style open-world vibe (neon skyline, wanted stars),
without using any third-party trademark. Your Agent ID is your wanted star.

## What it does

- Any wallet holding a Binance **Agent ID** (SPACE ID, `.ai`, ERC-721, non-transferable)
  can mint **1 free Pioneer badge** — gas only, no payment, no whitelist.
- The contract checks Agent ID ownership **on-chain** by calling `balanceOf`
  on the official Agent ID contract (`0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F`).
- 1 mint per wallet, max supply 10,000. Fully open-source, verified on BscScan.
- Each badge is a Neon City wanted-star collectible with traits (District, Ride,
  Wanted Level 5). Metadata in `site/metadata/` (generated by `generate_metadata.js`).

## Why

Agent ID is the on-chain name of an Agentic Wallet. This project turns that
identity into something tangible: a badge that proves you were an early Agent ID
holder, and a reason for Agent ID holders to interact on-chain. The Neon City
theme rides the open-world / GTA-style FOMO that is bringing new users on-chain
right now — the badge is the hook, the Agent ID gate is the real utility.

## How to mint

1. Open the website, connect your wallet (Binance Wallet / MetaMask) on BNB Chain.
2. The site checks your Agent ID balance on-chain.
3. If you hold an Agent ID and haven't minted, press **Mint**. You pay only gas.

## Development

- Solidity 0.8.26, OpenZeppelin Contracts 5.0.2 (ERC721 + Ownable), optimizer runs 200.
- Compile: `node compile.js` (outputs `build/AgentIDPioneer.json`).
- Deploy: deployed 2026-11-18 from wellsky via the Arachnid CREATE2 factory (`0x4e59b44847b379578588920ca78fbf26c0b4956c`), salt 0x01. See `build/deployment.json`.
- Website: static site in `site/` (`index.html` + `badge.svg`).

## Safety

- No payments: `mint()` is free, only gas. The contract holds no funds.
- No approvals, no transfers of user assets, no QR login, no credential collection.
- Owner can only change the metadata base URI (`setBaseURI`) — no minting,
  pausing, or fund withdrawal beyond the standard Ownable functions.
